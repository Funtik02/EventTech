# EventTech

Сервис для организации и управления мероприятиями (хакатон «EventTech»).
Организатор создаёт мероприятие, получает типовой план подготовки, распределяет задачи по команде,
ведёт бюджет, собирает регистрации гостей по публичной ссылке и следит за прогрессом на главной.

## Стек

- **Фронтенд:** React 19, Vite, React Router, lucide-react, обычный CSS с дизайн-токенами из макета
- **Бэкенд:** Node.js 24, Express 5, JWT-авторизация, bcrypt (папка `server/`)
- **База данных:** PostgreSQL (схема — `server/db/schema.sql`, демо-данные — `server/db/seed.sql`)

## Запуск

1. Установите PostgreSQL (вместе с pgAdmin 4) и создайте пустую базу `eventtech`.
2. Скопируйте `server/.env.example` в `server/.env` и впишите пароль от PostgreSQL.
3. Установите зависимости и создайте таблицы с демо-данными:

   ```bash
   npm install
   npm install --prefix server
   npm run db:init
   ```

4. Запустите API и фронтенд в двух терминалах:

   ```bash
   npm run server
   ```

   ```bash
   npm run dev
   ```

5. Откройте http://localhost:5173 и нажмите «Войти в демо-аккаунт».

Схему можно применить и вручную: откройте `server/db/schema.sql`, затем `seed.sql` в pgAdmin → Query Tool → Execute.

Для демо одним процессом: `npm run build`, затем `npm start --prefix server` — сервер отдаст и API, и собранный фронтенд на http://localhost:3001.

## Разделы

| Раздел | Что умеет |
|---|---|
| Главная | Карточка мероприятия, обратный отсчёт, задачи / бюджет / участники с прогрессом, ближайшие задачи, календарь |
| Мероприятия | Список мероприятий, переключение текущего, мастер создания в 3 шага с типовым планом |
| Задачи | Фильтры Все / Мои / Просроченные / Выполненные, поиск, исполнители, приоритеты |
| Бюджет | Лимит, план/факт по статьям, отклонения, разбивка по категориям |
| Участники | Публичная ссылка на регистрацию, статусы гостей, поиск, экспорт в CSV |
| Команда | Участники команды, роли, нагрузка по задачам |
| Календарь | Задачи и дни мероприятия на месячной сетке |
| Настройки | Профиль и параметры мероприятия, открытие/закрытие регистрации |

Публичная страница регистрации гостя: `/r/<id мероприятия>`.

## API

Все маршруты под `/api`, кроме `/auth/*` и `/public/*` требуют заголовок `Authorization: Bearer <token>`.

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/auth/register`, `/auth/login` | Регистрация и вход |
| GET / PATCH | `/auth/me` | Профиль |
| GET / POST | `/events` | Список / создание (`team`, `plan_template`) |
| GET / PATCH / DELETE | `/events/:id` | Мероприятие |
| GET | `/events/:id/summary` | Сводка для главной |
| GET / POST | `/events/:id/{tasks,team,budget,guests}` | Список / создание |
| PATCH / DELETE | `/{tasks,team,budget,guests}/:id` | Изменение / удаление |
| GET | `/public/events/:id` | Публичная информация о мероприятии |
| POST | `/public/events/:id/register` | Регистрация гостя |
